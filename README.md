### Webapps course
Educational materials, exercises, and full-stack projects from my high school web applications course, spanning 2023 to 2024.

**Elements:**
- **Lessons (2023-2024):** Core web concepts covering basic Node.js servers, request parameters, JSON responses, Express routing, and Vue 3 frontend configurations.
- **filemanager & filemanager-2 (2023):** Server-side web file managers built on Node.js to upload, create, delete, and browse files/directories on the server.
- **project-cars (2023):** A dynamic database-driven cars inventory management app.
- **store (2024):** A full-stack e-commerce project composed of a Vue 3/Tailwind CSS frontend and a Node.js/TypeScript backend API.

**Build using:**  
Node.js, Express, Vue, Vite, Tailwind CSS, & TypeScript

### Native course
A compilation of mobile application assignments and projects from my native app development course, including calculators, forms, and an AR app.

**Elements:**
- **lekcja1:** Introduction to React Native basics, styling layouts, and working with Flexbox.
- **project-calc:** A basic calculator app built with custom buttons and calculation logic.
- **note-app:** A stylish note-taking mobile application with tag category management, search filters, detail screens, and secure local storage using `SecureStore`.
- **register:** An app showcasing form validation, authentication views, stack navigation, and backend interaction setup.
- **ar-app:** A complex augmented reality app separated into mobile React Native/Expo viewports, a web client, and an express server backend.

**Build using:**  
React Native & Expo

### Svelte course
Practical exercises and projects for building Svelte application interfaces, featuring a Pokemon catalog app and interactive quizzes.

**Elements:**
- **lekcja-01 & lekcja-02:** Introductory lessons on Svelte reactivity, data-binding, properties, and custom components (like `Slider.svelte`).
- **quiz:** An interactive multi-question quiz application with data models.
- **countries:** A countries information portal rendering country details and stats dynamically.
- **PokeApp:** A Pokemon quiz and dashboard utilizing Svelte stores (`store.ts`) and modular layout components.

**Build using:**  
SvelteKit, Tailwind CSS, & TypeScript

### Server course
Educational curriculum and project materials for back-end web development, teaching backend routes, templates, database design, and user authentication.

**Elements:**
- **01-BasicApp:** Introduction to Python web servers with simple Flask routes and responses.
- **02-Bootstrap:** Integration of modern Bootstrap layouts with Flask dynamic templates.
- **03-Forms:** Request parameters and HTML form data handling, parsing, and server-side logic.
- **04-Grades:** A gradebook application structure to model, display, and manage student grades.
- **05-Users:** A complete user management module featuring registration, secure login sessions, user databases, and access control levels.

**Build using:**  
Python, Flask, Django, Jinja, & Bootstrap
